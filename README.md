# Анна · Искусство гармонии

Готовый статический сайт для GitHub Pages. Не требует сборки, Node.js, npm или внешнего хостинга изображений.

## Просмотр

Откройте `index.html` в браузере. Все изображения находятся в `assets/`. Веб-шрифты загружаются через Google Fonts; если они недоступны, используются системные шрифты.

## Публикация через GitHub Pages

1. Создайте **новый** репозиторий GitHub, например `anna-iskusstvo-garmonii`. Для бесплатной публикации через GitHub Pages репозиторий обычно должен быть публичным.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `assets/`, `.nojekyll`, `README.md`.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Дождитесь публикации. Адрес будет вида `https://USERNAME.github.io/anna-iskusstvo-garmonii/`.
5. Проверьте на телефоне открытие всех 9 разделов, фотографии и навигацию. После этого можно создавать QR-код на опубликованный адрес.

## Важно о конфиденциальности

Сайт содержит реальные фотографии Ани. **Публичный GitHub Pages доступен всем, у кого есть ссылка, и может индексироваться поисковыми системами.** Перед публикацией убедитесь, что Аня согласна на размещение фотографий. Если требуется приватный доступ, GitHub Pages публичного репозитория не подходит.

## Редактирование

Тексты и оформление находятся в `index.html`, изображения — в `assets/`. Сохраняйте имена файлов или обновляйте пути `src` при замене изображений. Разделы раскрываются встроенным HTML `<details>` даже без JavaScript. Небольшой JavaScript только автоматически раскрывает нужный раздел при переходе из содержания.

## Пароль

Содержимое страницы зашифровано (AES-256-GCM) и открывается только после ввода пароля. После первого ввода браузер запоминает пароль.

- Открытый исходник лежит в `_source/index.html` (не коммитится). Если его нет, восстановите: `python3 tools/protect.py decrypt ПАРОЛЬ`.
- Правьте `_source/index.html`, затем зашифруйте: `python3 tools/protect.py encrypt ПАРОЛЬ` и закоммитьте `index.html`.
- Сменить пароль: `decrypt` со старым паролем, затем `encrypt` с новым.
- Фотографии в `assets/` не шифруются: зная прямой адрес файла, его можно открыть без пароля.
